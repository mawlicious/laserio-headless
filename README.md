# LaserIO Headless

An unofficial Minecraft 1.20.1 Forge fork of LaserIO 1.6.8 that replaces AWT
color handling so laser block entities can load without native desktop libraries.

The full source and build instructions are being introduced through a pull request.
Upstream: https://github.com/Direwolf20-MC/LaserIO
